# Hadronic cross sections and timelike vacuum polarization

[Download the v13 data release](https://github.com/xkDong/Hadronic-cross-sections-and-VP-factors/releases/tag/v13).

| Dataset | Contents |
| --- | --- |
| [Global](https://github.com/xkDong/Hadronic-cross-sections-and-VP-factors/releases/download/v13/global-v13.zip) | Total hadronic Born cross section, hadronic $R$ ratio and timelike vacuum polarization on 39,137 energy points, with a reader for the cross-energy covariance. |
| [Charm](https://github.com/xkDong/Hadronic-cross-sections-and-VP-factors/releases/download/v13/charm-v13.zip) | Regional spectrum from 3.7 to 5 GeV, charm contributions and covariance matrices. |
| [Bottom](https://github.com/xkDong/Hadronic-cross-sections-and-VP-factors/releases/download/v13/bottom-v13.zip) | Regional spectrum from 10.55852 to 11.2062 GeV, observed and ISR-corrected open-bottom scan and covariance matrices. |

Each archive includes a README with units and column definitions. Covariances describe first-order propagation conditional on the spectral model. The global table also gives pointwise nonlinear intervals near narrow resonances.
