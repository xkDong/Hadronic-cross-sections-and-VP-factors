# Hadronic cross sections and timelike vacuum polarization

[Download the v13 data release](https://github.com/xkDong/Hadronic-cross-sections-and-VP-factors/releases/tag/v13-compact).

| Dataset | Contents |
| --- | --- |
| [Global](https://github.com/xkDong/Hadronic-cross-sections-and-VP-factors/releases/download/v13-compact/global-v13.zip) | Total hadronic Born cross section, hadronic $R$ ratio and timelike vacuum polarization on 17,554 energy points, with a reader for the cross-energy covariance. |
| [Charm](https://github.com/xkDong/Hadronic-cross-sections-and-VP-factors/releases/download/v13-compact/charm-v13.zip) | Regional spectrum from 3.7 to 5 GeV, charm contributions and covariance matrices. |
| [Bottom](https://github.com/xkDong/Hadronic-cross-sections-and-VP-factors/releases/download/v13-compact/bottom-v13.zip) | Regional spectrum from 10.55852 to 11.2062 GeV, observed and ISR-corrected open-bottom scan and covariance matrices. |

The output grid is refined around narrow resonances. At the 39,137 reference energies, linear interpolation in energy reproduces the central $R$ and $V$ curves to within 0.1%.

Each archive includes a README with units and column definitions. Covariances describe first-order propagation conditional on the spectral model. The global table also gives pointwise nonlinear intervals near narrow resonances.
